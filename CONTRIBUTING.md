# Contributing to This Learning Repository

This is a personal sandbox/learning repository, but you're welcome to suggest improvements or share ideas!

## Adding New Content

When adding new learning materials or experiments, consider:

### Organization
- Place code in the appropriate directory (`examples/`, `experiments/`, `notes/`, or `projects/`)
- Create subdirectories for different topics or technologies
- Use clear, descriptive names for folders and files

### Documentation
- Add a README.md to new project folders explaining:
  - What the code does
  - What you're learning
  - How to run it (if applicable)
  - Resources or tutorials followed
  - Any issues or learnings

### Code Quality
- This is a learning repo, so perfection isn't required!
- But do try to:
  - Include comments explaining your learning
  - Note any questions or confusion
  - Document interesting discoveries
  - Keep experiments focused and manageable

### Commit Messages
- Use clear, descriptive commit messages
- Examples:
  - `Add React hooks example from tutorial`
  - `Experiment with Python decorators`
  - `Complete JavaScript algorithm practice`
  - `Add notes on Docker networking`

## Sharing and Feedback

If you're exploring this repository:
- Feel free to open issues with questions or suggestions
- Pull requests with corrections or improvements are welcome
- Share your own learning experiences!

## What NOT to Include

- Sensitive information (API keys, passwords, etc.)
- Copyrighted code that you don't have permission to share
- Large binary files or datasets
- Production credentials or configurations

## Questions?

This is a learning space, so all questions are welcome! Open an issue if you want to discuss anything.
