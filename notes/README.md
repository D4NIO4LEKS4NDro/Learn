# Notes

This directory contains learning notes, documentation, and knowledge documentation.

## What Goes Here

- Learning notes and summaries
- Concept explanations in your own words
- Cheat sheets and quick references
- Technical documentation
- TIL (Today I Learned) entries

## Format

Notes can be in any format:
- Markdown files (`.md`)
- Text files
- Code comments
- Jupyter notebooks
- Whatever helps you learn!
